# SPEC.md

System specifications for Jab that lock-in system requirements.

Nomenclature: `{res}{req}{ver}`
- Resolution (`res`)
  - `1K` 1080p
  - `2k` QHD
  - `4K` 4K
- Requirements (`req`)
  - `/[A-Z]/` Hardware components and resources
- Version (`ver`)
  - `/[0-9]+/` Compatability, etc (eg, RVA22 vs RVA23)
