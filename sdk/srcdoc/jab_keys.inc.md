# jab_keys.inc

The key codes jab.sys.keyboard.input reports, Linux's own
(input-event-codes.h), and the values that come with them. Included by
jab.inc.

## .set JAB_KEY_RELEASED

`i32`: a key event's value as the key goes up.

## .set JAB_KEY_PRESSED

`i32`: a key event's value as the key goes down.

## .set JAB_KEY_HELD

`i32`: a key event's value while the key is held and repeats.
