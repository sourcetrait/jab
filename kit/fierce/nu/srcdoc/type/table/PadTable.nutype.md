# PadTable.nutype

The shape of a pad table, `nu/nuon/table/<name>.nuon`: evdev events in
order, each its time from the launch (`at`), its `type` (3 an axis, 1 a
button), its `code`, and its `value`, the reference pad's axes 0 to 255
about 127. `padtable held` holds a table to it through the SDK's `nutype
problems`.
