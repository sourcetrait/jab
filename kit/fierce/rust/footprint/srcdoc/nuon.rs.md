# nuon.rs

NUON is the user-visible wire format for typed values; the tool writes the
few shapes it needs by hand, records, lists, and scalars, so nushell reads
its answer with `from nuon`.

## enum Nuon

A float prints through its debug form, which keeps a fraction or an
exponent nushell reads as a float, and a value that is not finite prints
null.
