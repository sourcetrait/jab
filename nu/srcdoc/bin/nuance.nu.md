# nuance.nu

The workspace's nuanced verbs that a user testing on a host runs, each
one call of an SDK module over the workspace this file sits in: a
bench's watch and the target's housekeeping (the campaign's decision 1).
Every other command for development is its own tree's.

## main watch bench

`watcher bench`: with `<program>/<bench>`, the bench's run in progress
taken up, or its next waited for, every QEMU of it recorded per thread
under the step its command line names, and at its end the bench's report
and one per QEMU printed, `watch.nuon` written, and the run packed again
into the tar it names last; with no bench, the benches listed.

## main clean

`build clean`: the workspace checked, then the whole target retired with
no path, else the outputs of the programs at or under it, or the
kernel's with `kernel`, in both trees or the one `--tree` names.
`--wrapped` passes `--tree` and its tree through as words.

## main retire

`build retire`: the workspace checked, then the retire home's tmp
deleted, the one deletion the tools make.
