# sdl

The sdl children's api in one import for a consumer: a `use` of
`nu/mod/sdl` by its path from the consumer, then each by the name below.
No child imports it; each imports its siblings by path.

- `sdl bundle`: sdl/bundle's `main`.
- `sdl bundle-check`: sdl/bundle's `bundle-check`.
- `sdl trace-bracket`: sdl/bundle's `trace-bracket`.
- `sdl classify`: sdl/classify's `main`.
- `sdl log`: sdl/log's `main`.
- `sdl pair`: sdl/pair's `main`.
- `sdl report`: sdl/report's `main`.
- `sdl resolve`: sdl/symbols's `resolve`.
