# mod.nu

The SDK's launch in the form a script's command line can give it, for
`nu/bin/nuance/launch.nu`: every flag `launch` takes, those it takes as a
table or a list, `--keys`, `--send`, `--threads-at`, and `--qemu`, as NUON
text, and the record it returns printed as NUON, the API's bytes as binary,
for a harness in another checkout to read.
